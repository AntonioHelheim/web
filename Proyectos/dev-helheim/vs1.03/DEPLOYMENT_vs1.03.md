# Despliegue — Helheim.cl vs1.03

Subir el contenido de la carpeta `vs1.03` conservando su estructura de directorios.

Requisitos:

- Servidor web capaz de servir HTML/CSS/JS.
- PHP 7.3+ para `php/contact.php`.
- MySQL no es necesario en esta versión.
- Para correo real se mantiene la configuración SMTP/mail definida en la documentación de contacto de la versión previa.

Después del despliegue conviene hacer una recarga forzada del navegador por el cambio de assets y cache-busting.
