# E3-VS1 — Unificación visual del onboarding

El Paso 1 de datos de usuario adopta el mismo sistema visual del cuestionario.

## Secciones

Las seis secciones usan acentos rotativos:
- azul;
- cian;
- violeta;
- ámbar;
- índigo.

No se usan rojo o verde durante la captura de información.

## Alternativas

Mutualidad, radios y checkboxes de salud, antecedentes y consentimiento:
- conservan el control nativo;
- resaltan toda la alternativa;
- resaltan el bloque relacionado;
- animan brevemente la selección.

## Responsive

- Escritorio: mayor ancho útil y grupos de selección hasta tres columnas.
- Tablet: dos columnas.
- Teléfono: una columna.
- Se preserva `prefers-reduced-motion`.

No cambia ninguna regla de validación ni persistencia.
